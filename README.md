# 📊 Data Jobs Dashboards (Power BI)

This repository contains two Power BI projects exploring data-related job postings. The first dashboard was built as a hands-on introduction to Power BI visuals and interactions. **Data Jobs Dashboard 2.0** continues the analysis with an overview of in-demand skills and salary comparisons by role.

## 📁 Repository Contents

| Folder or file | Description |
|---|---|
| [`Data_Jobs_v1/`](Data_Jobs_v1/) | First dashboard project, with its report and project README |
| [`Data_Jobs_v2/`](Data_Jobs_v2/) | Second dashboard project, with its report and project README |
| [`images/`](images/) | Dashboard screenshots |

## 🖥️ Latest Dashboard — Data Jobs Dashboard 2.0

The v2 dashboard summarizes nearly **479K job postings** and includes job-title and country filters, key salary metrics, a top-skills comparison, and salary comparisons across data roles.

![Data Jobs Dashboard 2.0 overview](images/Screenshot%202026-09-25%20234056.png)

Open [`Data_Jobs_v2/README.md`](Data_Jobs_v2/README.md) for the full v2 project details and usage instructions.

## 📊 Earlier Project — Data Jobs Dashboard

The v1 project explores job trends, salaries, job types, hiring platforms, and global job distribution across two report pages. Its README includes the dashboard screenshots, visual details, and instructions.

Open [`Data_Jobs_v1/README.md`](Data_Jobs_v1/README.md) for the v1 project overview.

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the `.pbix` report in the relevant project folder with [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. See that version's README for its dashboard details and interaction guidance.
